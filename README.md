# film_synopsis — 영화 기획실

**제1회 대한민국 AI창작문학상 영화 부문** 응모작을 사람 작가 한 명과 AI 크루 아홉이 함께 만드는 저장소입니다.
기획부터 제출까지 과정 전체를 기록합니다. 이 기록은 공모전 필수 제출물인 프롬프트 노트의 원재료가 되고, 나중에는 과정 영상의 재료가 됩니다.

## 크루

[동화 공방(fairy_tale)](https://github.com/heekeunlee/fairy_tale)의 서브에이전트 구조를 영화 공모전에 맞게 옮겨 확장했습니다. 크루는 제안하고, 쓰고, 비평하고, 기록합니다. **로그라인 선택, 방향 결정, 제출본의 문장은 작가가 합니다.**

| 커맨드 | 담당 | 하는 일 |
|---|---|---|
| `/research [주제]` | 리서처 | 영화·드라마·OTT 동향, 유사작·저작권 리스크 점검 |
| `/plan 발굴` · `/plan <로그라인>` | 기획 PD | 로그라인 후보 15~20개 / 캐릭터·3막·결말까지 기획서 |
| `/write [기획서]` | 시나리오 작가 | A4 3~5매 제출 규격 기획안 AI 초안 (실제 매수 확인) |
| `/review [원고]` | 심사위원 | 요강 규격 점검 + 심사 기준 모의 채점 (50/30/20) |
| `/consult [작품]` | 고문 (프로듀서) | 피칭 데이 관점: 시장성, 제작 현실성, 확장성 |
| `/visual [작품 또는 영상]` | 비주얼 디렉터 | 포스터·키 비주얼 이미지 프롬프트 / 과정 영상 스토리보드 |
| `/pitch [작품]` | 피칭 담당 | 한 줄 카피, 60초·3분 피치, 제출 메일 초안 |
| `/audit` | 라인 PD | D-day, 실제 매수, 정합성, 기록 누락, 제출 체크리스트 |
| `/log` · `/promptnote` | 메이킹 기록자 | 창작 일지·결정로그 기록 / 프롬프트 노트 초안 |

### 동화 공방에서 달라진 점
- **사람 작가가 쇼러너.** 작가 결정 관문(◆)을 파이프라인에 명시하고, 제출본은 작가 수정본(`-author`)만 씁니다.
- **공모전 맞춤 모의 심사.** 요강 규격과 심사 기준 배점으로 채점합니다.
- **실제 A4 매수 측정.** `scripts/build_pdf.py`가 11pt PDF를 만들어 매수를 셉니다.
- **기록 담당 추가.** 모든 크루 호출이 일지에 남고, 그 기록이 프롬프트 노트(심사 30%)가 됩니다.
- **오피스 통계 자동화.** 손으로 고치던 크루 통계를 GitHub Actions가 실제 파일과 git 이력에서 계산합니다.

## 구조
```
기획전략.md                 요강 정리와 전략
CLAUDE.md                   기획실 도면: 크루, 워크플로우, 기록 규칙, 명명 규칙
.claude/agents/             서브에이전트 정의 9개
.claude/commands/           슬래시 커맨드 10개
research/ ideas/ planning/  조사, 로그라인 후보, 기획서
drafts/ reviews/ advisory/  원고(AI 초안·작가 수정본), 모의 심사, 프로듀서 검토
visual/ pitch/ submission/  비주얼 기획, 피칭 자료, 제출물
admin/                      라인 PD 점검
journal/                    창작 일지, 결정로그, 일지 템플릿
video/                      과정 영상 장면 후보, 스토리보드
assets/                     AI 이미지, 스크린샷 (버전 번호로 관리)
scripts/build_pdf.py        원고 → A4 11pt PDF, 실제 매수 확인
scripts/build_site_data.py  저장소 → 오피스 화면 데이터
site/                       오피스 화면 (GitHub Pages)
```

## 로컬에서 쓰기
```bash
python3 scripts/build_pdf.py drafts/작품-v1.md      # 실제 A4 매수 확인 (Chrome 필요)
python3 scripts/build_site_data.py && cd site && python3 -m http.server 8080   # 오피스 화면 미리보기
```
