이번 세션을 기록해줘. $ARGUMENTS

recorder 서브에이전트는 이 대화를 볼 수 없어. 먼저 네가 아래 원자료를 정리해서 넘겨줘:
1. 이번 세션의 사용자 프롬프트 **원문 전부** (슬래시 커맨드 포함, 요약 금지)
2. 실행한 크루 커맨드와 각 산출물 경로
3. 작가가 **실제로 말한** 결정과 이유 (추측 금지. 말하지 않았으면 "없음")
4. 이번 세션에서 영상에 쓸 만한 순간 후보
5. 오늘 날짜와 대략의 세션 시간

recorder 서브에이전트가 일지, 결정로그, 장면 후보, README 진행 현황을 정리하면, 작가에게 확인이 필요한 빈칸을 보여주고 변경 사항을 커밋해서 `main`에 push해줘. 커밋 메시지는 `[journal] ...`로 시작해.
